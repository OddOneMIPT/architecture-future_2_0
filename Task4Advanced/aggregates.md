# Агрегаты «Будущее 2.0»

Ключевые агрегаты доменной модели: границы транзакционной согласованности, инварианты и
идентификаторы. Один агрегат = одна граница согласованности (изменяется в одной транзакции,
публикует доменные события через outbox).

---

## КредитныйДоговор (Lending)

- **Корень агрегата:** `КредитныйДоговор`
- **Ключ:** `loan_id` (UUID)
- **Сущности/VO:** `ГрафикПлатежей`, `Заёмщик(ИдентификаторКлиента)`, `Сумма`, `Ставка`, `Статус`
- **Инварианты:**
  - Сумма договора > 0; ставка ≥ 0.
  - Договор привязан к существующему `ИдентификаторКлиента` (из Customer 360).
  - Сумма графика платежей = сумма основного долга + проценты.
  - Переход статусов: `Черновик → Активен → (Погашен | Просрочен | Закрыт)`; нельзя погасить черновик.
- **События:** `СозданКредитныйДоговор`, `КредитПогашен`, `КредитПросрочен`

## Пациент (Patient Care)

- **Корень:** `Пациент`
- **Ключ:** `patient_id` (UUID), связан с `ИдентификаторКлиента`
- **Сущности/VO:** `МаршрутПациента`, `Приём`, `Согласие` (на обработку данных)
- **Инварианты:**
  - Пациент уникален по идентичности (нет дублей в рамках клиники).
  - Регистрация невозможна без действующего `Согласие` на обработку ПДн.
  - Мед.карта и результаты исследований — часть защищённого контура; **не сериализуются в публичные события**.
- **События:** `ЗарегистрированПациент`, `МаршрутОбновлён`

## ИсследованиеИИ (Diagnostics AI)

- **Корень:** `ИсследованиеИИ`
- **Ключ:** `study_id` (UUID); ссылается на `patient_id`
- **Сущности/VO:** `Модель`, `Статус`, `Заключение(защищённое)`, `Метрики`
- **Инварианты:**
  - Исследование привязано к существующему пациенту.
  - Переход: `Назначено → Выполняется → (Завершено | Ошибка)`.
  - В публичное событие выходит **факт и статус**, без содержимого заключения.
- **События:** `ПройденоИсследованиеИИ`, `ИсследованиеОшибка`

## Платёж (Payments & Billing)

- **Корень:** `Платёж`
- **Ключ:** `payment_id` (UUID); опц. ссылка на `loan_id` / `invoice_id`
- **Сущности/VO:** `Сумма`, `Валюта`, `Статус`, `Метод`
- **Инварианты:**
  - Сумма > 0; валюта из справочника.
  - Идемпотентность по ключу запроса (нет двойного списания).
  - Переход: `Создан → Авторизован → (Проведён | Отклонён | Возврат)`.
- **События:** `ПлатёжПроведён`, `ПлатёжОтклонён`, `СчётВыставлен`

## Счёт (Payments & Billing)

- **Корень:** `Счёт`
- **Ключ:** `invoice_id` (UUID)
- **Инварианты:** сумма счёта = Σ позиций; счёт нельзя оплатить дважды; статус `Выставлен → Оплачен | Аннулирован`.
- **События:** `СчётВыставлен`, `СчётОплачен`

## ПозицияСклада (Inventory & Supply)

- **Корень:** `ПозицияСклада`
- **Ключ:** `sku_id` (+ `location_id`)
- **Инварианты:** остаток ≥ 0; списание не больше доступного; резерв ≤ остаток.
- **События:** `ИзмененОстаток`, `ПозицияЗакончилась`

## ФинансовыйПериод (Finance & Reporting)

- **Корень:** `ФинансовыйПериод`
- **Ключ:** `period_id` (например, `2026-Q2`)
- **Инварианты:** закрытый период неизменяем; отчёт формируется только по закрытому периоду; баланс сходится.
- **События:** `ОтчётСформирован`, `ПериодЗакрыт`

## Клиент (Customer 360)

- **Корень:** `Клиент`
- **Ключ:** `customer_id` = **ИдентификаторКлиента** (Published Language для всех доменов)
- **Инварианты:** единый профиль без дублей; хранит согласия; источник истины по идентичности.
- **События:** `КлиентСоздан`, `КлиентОбновлён`
