# Task5Advanced — Техрадар, TCO и роадмап Data Mesh

Задание 5: спроектировать целевой технологический ландшафт и выполнить стоимостной анализ.

## Состав

| Файл | Содержание |
|------|------------|
| [`tech-radar.md`](./tech-radar.md) | Расширенный техрадар: технологии **и** архитектурные паттерны (Data Mesh, EDA, Self-service BI) со статусами **Adopt / Trial / Assess / Hold**. 4 квадранта + визуализация колец. |
| [`tco-analysis.md`](./tco-analysis.md) | TCO-модель «текущая vs целевая» на 3 года: инфраструктура, лицензии, сопровождение, время аналитиков, миграция; дельта и точка окупаемости. |
| [`roadmap.md`](./roadmap.md) | Стратегический роадмап Data Mesh: роли (Data Product Owner, Data Engineer, BI-аналитик, Platform Team, Governance), этапы пилот → масштабирование → поддержка, привязка к бизнес-целям. Gantt + таблицы. |

## Краткие выводы

- **Техрадар.** Ядро целевой платформы (EDA, контракты событий, Kafka, IaC) — **Adopt**;
  элементы Data Mesh (Data Mesh, Self-service BI, Lakehouse, CDC, dbt) — **Trial**; точечные
  усиления (Event Sourcing, CQRS, Trino) — **Assess**; весь легаси (SQL Server 2008, PowerBuilder,
  синхронный Camel) — **Hold**.
- **TCO.** На 3-летнем горизонте целевая архитектура дешевле в сумме (≈550 против ≈592 млн ₽) и
  существенно дешевле к году 3 (132 против 215); год 1 — инвестиционный, окупаемость в течение года 2.
- **Роадмап.** Три этапа (0–6 / 6–18 / 18–36 мес) с ролями и привязкой к бизнес-целям —
  от пилота до доменной потоковой аналитики и вывода легаси.
